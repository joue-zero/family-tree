# شجرة العيلة

موقع ثابت (من غير سيرفر ولا قاعدة بيانات). كل البيانات في ملف واحد: `data/family.json`، والصور في `photos/`.
أي تعديل بيتحفظ كـ commit في الريبو، والـ GitHub Actions بتعمل تحقق وتنشر الموقع على GitHub Pages تلقائيًا.

## التشغيل أول مرة

1. اعمل ريبو جديد على GitHub (مثلاً `family-tree`) وارفع الملفات دي عليه (branch اسمه `main`).
2. من **Settings → Pages** اختار **Source: GitHub Actions**.
3. بعد أول push هيشتغل الـ workflow، والموقع هيبقى على `https://USERNAME.github.io/family-tree/`.

## إضافة ناس

1. اعمل **Fine-grained token** من GitHub → Settings → Developer settings، للريبو ده بس، بصلاحية **Contents: Read and write**.
2. افتح الموقع → ⚙ الإعدادات → حط اسم المستخدم واسم الريبو والـ Token (بيتخزن في متصفحك بس).
3. دوس **✎ تعديل**، اختار أي شخص، وأضف: ابن/بنت، زوج/زوجة، أب/أم، أخ/أخت.
   - «حفظ وإضافة غيره» عشان تضيف إخوات أو أولاد ورا بعض بسرعة.
   - لو الشخص موجود بالفعل (جواز أقارب مثلاً) اختار تبويب «شخص موجود في الشجرة» وهيتربط من غير تكرار.
4. دوس **حفظ** → بيعمل commit واحد (البيانات + الصور)، والموقع بيتحدّث بعد حوالي دقيقة.

### تفاصيل وصور وصلة القرابة

- في نافذة التعديل (✎ تعديل البيانات) تقدر تضيف **تفاصيل إضافية** (الوظيفة، العنوان، تاريخ الجواز… أي عنوان تحبه) و**ألبوم صور** لكل شخص. بتظهر في لوحة الشخص، والصور بتتفتح كبيرة بالضغط عليها.
- زرار **⚖ صلة القرابة** فوق: دوس عليه واختار شخصين أو أكتر من الشجرة، وهيطلعلك صلة كل اتنين ببعض (ابن عم، خال، زوجة عمه…) والجد المشترك. الحساب من بيانات الأب/الأم والجواز، فلو الصلة طلعت ناقصة يبقى فيه حد ناقص في الشجرة.

التعديلات بتتحفظ مؤقتًا في المتصفح لحد ما تدوس حفظ. ولو اتنين عدّلوا في نفس الوقت، بيتدمج تعديل كل واحد (بحسب الشخص).
اللي مفيش معاه Token بيشوف الموقع بس.

## تشغيل محلي

```bash
python -m http.server 8123
```

وافتح `http://localhost:8123`.

## شكل البيانات

```json
{ "id": "p3", "name": "محمود عبد الرحمن", "gender": "m", "birth": "1952",
  "parents": ["p1", "p2"], "spouses": ["p6"], "photo": "photos/p3.jpg" }
```

العلاقات بتتحدد بـ `parents` (لحد 2) و`spouses`، والباقي (الأبناء، الإخوة) بيتحسب لوحده.
`node scripts/validate.mjs` بيتأكد من سلامة الملف، وبيشتغل في الـ CI قبل أي نشر.

## ملاحظة خصوصية

موقع GitHub Pages بيبقى عام على الإنترنت حتى لو الريبو private (إلا في خطط Enterprise).
متحطش بيانات حساسة (أرقام تليفونات مثلاً) إلا لو مش مشكلة إنها تتشاف.
